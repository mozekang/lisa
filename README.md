# Lisa の小さなお部屋

浏览器里的温馨房间小游戏。Node.js 18+，应用无第三方运行依赖。

```sh
cd /workspace/lisa
npm run dev
```

默认端口 3000，可用 `PORT` 覆盖。点击五个区域，Lisa 会绕开家具移动，到达后选择行动。点击空地自由移动。行动会影响状态条；状态仅保留在当前页面。时钟使用 Asia/Shanghai 时间。

## 图片资源

`public/assets/room.jpg` 为用户上传的新房间背景原文件，未重新生成或修改。`public/assets/lisa-run.png` 是根据角色参考生成的透明四帧奔跑精灵图，使用 CSS 帧动画播放。地图碰撞采用归一化矩形和网格寻路，后续更换地图需要同步调整 `public/app.js` 的区域和障碍物。

## 验证

`npm test` 使用当前云环境提供的 Playwright 和 `/usr/bin/chromium` 执行浏览器功能测试。其他环境需先安装 Playwright，并通过 `CHROMIUM_PATH` 指定 Chromium。测试前启动服务器。测试涵盖五个区域的到达和行动、帮助弹窗、桌面单屏布局、中日文切换及语言偏好保存及控制台错误。


## V1 桌面版

界面按桌面窗口的宽高缩放，房间保持 2:1 比例，不出现页面滚动条。验证尺寸：1920×1080、1440×900、1366×768、1280×720、1024×600；暂不提供移动端适配。

状态栏右侧齿轮打开设置，默认日文，可切换简体中文。静态界面、行动菜单、提示、状态、日期和无障碍标签同步切换；语言偏好保存在浏览器 localStorage 中，存储不可用时仍可当次切换。切换语言不会重置游戏状态。


## V2 房间主体

只保留卧室地图及上方状态栏，移除外围标题、介绍、快捷区域卡片和页脚；声音、设置、帮助保留在状态栏内。地图按窗口宽高等比放大，继续保持桌面单屏无滚动。

角色使用 `public/assets/lisa-directions.png`：四列跑动帧、三行（向右、向下、向上），向左使用侧面帧镜像。方向由每段实际移动向量决定，上下移动显示正面或背面，静止时保持最后朝向。原始正面素材保留用于头像。


## V3 背景音乐

设置中的“背景音乐”可启用/暂停循环播放、选择上传的 BGM 1 或 BGM 2，并通过滑块调整音乐音量（0–100%，默认 35%）。默认关闭音乐；点击状态栏音符或设置内的播放开关开始。音符按钮同时控制背景音乐与原有行动提示音，音量滑块只影响背景音乐。

曲目、音量和启用状态自动保存在当前浏览器中。恢复启用状态时会尝试播放；如果浏览器阻止自动播放，下一次点击或按 Enter/空格会重试。设置内会显示播放或加载失败状态。切换曲目从头播放，暂停后恢复继续播放。音乐资源原样使用用户上传的 `BGM1.mp3`、`BGM2.mp3`。

`npm test` 另包含真实浏览器音频解码及播放进度、切歌、音量边界、暂停、偏好保存和中文提示测试。


## V4 音乐精简

只保留 `public/assets/audio/BGM2.mp3`，删除 BGM1 文件及设置中的曲目选择。保留循环播放、播放开关、音量调节和浏览器偏好保存。旧版本存储的曲目字段会被清除，音量与启用状态保留，统一播放 BGM2。


V4 背景已替换为用户上传的原始 JPG。状态栏左上角标题为日文「妹のおうち」／中文「妹妹的家」，角色姓名仍为 Lisa。新增右侧门扇的碰撞范围。


## V5 独立图片组件与更新说明

房间现在使用透明 SVG 独立图片组件重新绘制，原始 `room.jpg` 保留。房基（地板和墙壁）与 14 个物品分别位于 `public/assets/objects/`，不再在 JPG 上覆盖热点。厨房操作台、洗衣机、烘干机、冰箱、微波炉、两个衣柜、床、书桌、椅子、床左侧长桌、小狗、花瓶和扫地机器人均有独立按钮、可访问名称和事件绑定，hover / 键盘焦点 / 当前选择显示白色轮廓。

`public/app.js` 的 `objects` 数组定义图片位置和到达点。按钮发出 `objectactivate` 事件，`event.detail.id` 标识物品，可继续独立扩展功能。保留原有五类行动；新增家具提供“查看”行动。地板点击继续自由移动。

点击工具栏 V5 打开更新记录，跟随设置中的中日文切换。每次后续更新必须同步维护 `public/releases.js` 的双语记录、版本按钮及 package 版本，规则见 `AGENTS.md`。唯一背景音乐仍为 BGM2。

`npm test` 增加逐件物品到达、白色 hover 轮廓、双语版本记录及键盘激活测试。

## V6 精致重绘素材

根据房间参考重新生成温暖可爱的 3D 微缩风格图片，替换 V5 的全部 SVG。房基为 1774×887 PNG；14 件物品分别是带透明通道的 PNG，原生尺寸约 171–649 像素，按屏幕中的物品尺寸缩小显示，不靠放大旧图制造细节。床、厨房、家电、衣柜等采用高密度单独重绘批次，重新呈现木纹、面料、金属和玻璃。

`art/v6/` 保留实际使用的三张新生成原稿；`scripts/export-v6.cjs` 只负责从新原稿导出独立资源及透明边距，不从用户参考图切图。可选素材导出步骤需要 Sharp（应用运行无需依赖）；在可用环境执行 `node scripts/export-v6.cjs`。房基原稿即 `public/assets/objects/foundation.png`。CSS 使用 `object-fit: contain` 保持原生比例，白色轮廓继续沿透明图片外形显示。碰撞同步更新右下隔间边界。

## V7 睡觉与吃饭

床的行动菜单新增「上床睡觉」：角色从床边起跳，经四帧跳跃、四帧落床/盖被/入睡动画，保持安睡；点击「起床」恢复角色并结算一次休息效果。新生成的床与角色帧位于 `public/assets/actions/`。

书桌、椅子和厨房的行动菜单新增「吃饭」。Lisa 先沿空地走到椅子旁，再坐下播放四帧夹面/吃面动画；桌面切换为只有卤牛腩和奶白汤拉面的晚餐。用餐期间点击餐桌直接打开「今晚菜品」双语弹窗；平时也可从书桌行动菜单查看并开始吃饭。点击「吃好了」结算一次饱腹效果，并恢复办公桌面。点击其他物品或地板可以中断动作，清除动画、恢复安全位置，不发放未完成奖励。

菜品根据用户照片重新生成：卤牛腩与花朵碗的奶白汤拉面；没有使用照片中的红汤面或白菜。原稿保留于 `art/v7/`；`scripts/export-v7.cjs` 使用 Sharp 导出透明独立帧与高清菜品 PNG。`public/activities.js` 负责资源预载、动作生命周期、状态恢复和餐桌弹窗。睡觉/吃饭状态不跨刷新保存。

`npm test` 增加真实浏览器验证：起跳到入睡、起床结算、坐椅吃饭、桌面替换、用餐中点击菜品菜单、结束恢复、动画中断不会残留回调或重复奖励、双语菜品与小屏桌面弹窗。
